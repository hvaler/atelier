# Demo video script

**This file no longer holds the script.** It held a fourth copy of the same sentences, with its own
hand-typed timings, and it went stale twice in one day while the narration was being cut from 6:23
down to 3:41.

Three copies of the same words is a guarantee that one of them eventually says something the others
do not — silently, and only visible to whoever reads the one that was not updated.

| What you want | Where it is |
|---|---|
| **The words** | [`demo/video/narration.md`](../demo/video/narration.md) — ten segments, each heading carrying the window measured off the generated audio |
| **What is on screen** | [`demo/video/shot-list.md`](../demo/video/shot-list.md) — nine clips, the app's measured response times, and how long each clip has to be |
| **How to record and edit it** | [`docs/VIDEO_RECORDING_RUNBOOK.md`](VIDEO_RECORDING_RUNBOOK.md), and the Spanish operational version outside the repository |
| **The tooling** | [`demo/video/README.md`](../demo/video/README.md) — voiceover, subtitles, closing card, assembly, alignment |

**Measured length: 3:41 of narration plus a five-second closing card — 3:46**, against a four-minute
limit where only the first four minutes are evaluated.

against. **It contains none of them**, and that is a decision rather than an omission.

**The pattern is worth naming.** Of eleven sources, exactly two carry an open licence, and neither
of those two could be stored: the CC BY‑SA textbook excludes its own figures, and the CC BY course
outline could not be downloaded. Everything else is an institutional web page or programme
specification with no licence statement at all, which means all rights reserved. Published
curricula are public to read and not free to redistribute, and the two are easy to confuse.

The analysis these sources support is in **[`../PEDAGOGY.md`](../PEDAGOGY.md)**, which paraphrases
and cites rather than reproducing — the CC BY‑SA text in particular, because ShareAlike would
extend to a derivative and this repository is Apache‑2.0.

**One source is deliberately unnamed.** The studio rubric the agent applies derives from real
instructor rubrics for formal perspective‑drawing coursework. It is described in `../PEDAGOGY.md`
by what it contains and never by where it came from, because naming the institution would identify
a person who did not ask to be identified. The published curricula above serve the citation need
instead, and they serve it better: they can be checked.

If a future source turns out to be CC BY, CC0 or public domain **and** retrievable, it belongs
here, with its licence recorded in the table above.

# References — why this directory holds no source files

This directory exists to hold third‑party pedagogical sources that Atelier's critique is calibrated
against. **It contains none of them**, and that is a decision rather than an omission.

Licence was checked before anything was downloaded. The outcome for each source:

| Source | Licence found | Stored | Why |
|---|---|---|---|
| Kennedy, *Drawing Perspectives, Volume 2 (Art‑005B)*, College of Lemoore, 2024 — [PDF](https://lemoorecollege.edu/oer/documents/2024-drawing-perspectives-art-005b-oer-textbook.pdf) | **CC BY‑SA 4.0** on the text | ✗ | The licence explicitly does not cover the figures: *"Some images are student work; all rights are reserved."* Committing the 121‑page PDF would redistribute that. |
| *ART 110 Basic Perspective*, BYU‑Idaho, Winter 2015 — [syllabus](https://courses.byui.edu/art110_new/Art110_S15/HTML/syllabus.html), [rubric](https://courses.byui.edu/art110_new/Art110_S15/HTML/rubric.html) | **None stated** | ✗ | No licence means all rights reserved. Short criterion wordings are quoted in `../PEDAGOGY.md` as quotation for commentary. |
| *Grado en Animación (Dibujo & Perspectiva)*, U‑tad Madrid — [plan](https://www.u-tad.com/estudios/grado-en-animacion/) | **University curriculum** | ✗ | Learning outcomes and criteria cited for layout perspective and 2-point benchmark progression. |
| Duddy, *Introduction to Architecture, ARCH 1101, Course Outline*, CUNY City Tech, 2017 — [record](https://academicworks.cuny.edu/ny_oers/58/) | **CC BY 4.0** | ✗ | Versionable in principle, but the download endpoint answers scripted requests with HTTP 202/403 and the document could not be obtained. It is also a course outline rather than a perspective chapter. |
| Pozzo, *Rules and Examples of Perspective*, 1693 — [Gutenberg #56312](http://www.gutenberg.org/files/56312/56312-h/56312-h.htm) | **Public domain** | ✗ | Freely storable; a link is sufficient for a 17th‑century treatise nobody needs offline. |

The analysis these sources support is in **[`../PEDAGOGY.md`](../PEDAGOGY.md)**, which paraphrases
and cites rather than reproducing — the CC BY‑SA text in particular, because ShareAlike would
extend to a derivative and this repository is Apache‑2.0.

If a future source turns out to be CC BY, CC0 or public domain **and** retrievable, it belongs
here, with its licence recorded in the table above.
